# Results

The original three corpus tables are generated by `python tools/make_results.py`,
which reads `runs/`. Follow-up reports are linked separately below.

Each corpus is measured twice. Against `baseline`, the ordinary transformer in the corpus's published configuration: what a model gives up for its parameter saving. Against `shared_qkv`, the shared projection the ana_* operators are built on and match in size: what the operator recovers.

The two carry different marks, so a symbol names the test it came from: `*` is p < 0.05 against `baseline`, `†` is p < 0.05 against `shared_qkv`.
